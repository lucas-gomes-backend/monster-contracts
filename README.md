# Monster Contracts (nome de trabalho)

Jogo 3D em primeira pessoa de investigação sobrenatural. Você é um caçador que aceita contratos para resolver casos envolvendo criaturas mitológicas e paranormais de todo o mundo — em um mundo procedural com casos procedurais.

Inspirações: *Supernatural* (tom e premissa), *Shadow of Doubt* (simulação e casos procedurais), *Return of Obra Dinn* (dedução), *The Witcher* (contratos e preparação).
